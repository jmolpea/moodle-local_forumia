# Forumia — AI Forum Assistant for Moodle™

[![Moodle 4.5 – 5.2](https://img.shields.io/badge/Moodle-4.5%20LTS%20%E2%80%93%205.2-orange)](https://moodle.org) [![PHP 8.2+](https://img.shields.io/badge/PHP-8.2%2B-blue)](https://php.net) [![License: GPL v3](https://img.shields.io/badge/License-GPLv3-green)](LICENSE)

**Component:** `local_forumia` · **By:** [Pluginia](https://pluginia.es), a trading name of RSMAX Consulting S.L.

Forumia replies to student forum posts with AI, suggests grades against your own criteria for a teacher to confirm, and revives discussions that have gone quiet. It publishes from a dedicated assistant account that the site administrator designates, labels every reply as AI-generated, and works only in the forums you choose, under limits you control.

---

## What it does

| | |
|---|---|
| **Immediate replies** | Answers each student post using your prompt and the forum's own description as context. The AI call runs from cron, never inside the student's request: replies appear on the next cron run, or one hour later if you prefer students to get first crack at answering each other. |
| **AI grading** | Opt-in, per forum, for forums with whole-forum grading. Each student is evaluated **once**, a configurable number of hours after their first post (12 by default), looking at all their posts: original contributions weigh more, and replies to classmates are judged with the classmate's message as context. Later posts never trigger a new evaluation. Two modes: **Suggest** (a teacher accepts or discards each grade, or all at once) and **Automatic**, for self-paced courses (the grade is applied only to students without a grade, never replacing one, and recorded under the teacher who switched it on). Replies to students never mention grades. |
| **Always labelled** | Every AI reply ends with a fixed notice saying it is AI-generated. Teachers can add their own disclaimer after it, but cannot remove it. |
| **Discussion reactivation** | After N days without a human reply, posts a short reply into the thread that picks up an existing point, adds an angle and asks one open question. Never starts empty threads. Stops at the forum due date. |
| **Daily digest** | One consolidated reply per day covering the last 24 hours of posts, with authorship anonymised. |
| **Four AI providers** | OpenAI (incl. Azure), Anthropic Claude, Google Gemini, DeepSeek. Bring your own key. |
| **Spend control** | Independent daily ceilings per user, per forum and site-wide. Auto-pause on provider rate limits; site-wide auto-disable and admin notification on auth failure. |
| **Backup & restore** | Per-forum configuration travels with course backups. |

## Installation

**Via the browser (recommended)**

1. **Site administration → Plugins → Install plugins**
2. Drop the ZIP in, leave the plugin type as *Detected*, install, and complete the database upgrade.

**From the server**

1. Unzip and copy the `forumia` folder to `<moodleroot>/local/forumia/`.
2. Visit **Site administration → Notifications**.

> The folder must be named exactly `forumia`.

### The assistant account

Forumia never publishes under the name of a real teacher or manager. Before enabling it in a forum, a site administrator designates the account it posts from:

1. Create a dedicated Moodle user for the assistant (for example *Course Assistant*).
2. Either enter its username in **Site administration → Plugins → Local plugins → Forumia → Default site-wide AI assistant account**, or give it a system-level role that holds `local/forumia:actasassistant` (useful if you want several assistant accounts).

Only those accounts appear in the forum settings. If the chosen account is later suspended, deleted or no longer designated, Forumia falls back to the site default account; if there is none, it disables itself in that forum and notifies the site administrators.

The daily digest runs at 08:00 server time by default. Change it in **Site administration → Server → Tasks → Scheduled tasks → Forumia – Daily Summary**.

Full setup — configuring the provider and enabling it in a forum — is in the [documentation](https://pluginia.es/forumia/docs).

## Privacy

**Leaves your site**, over HTTPS, to the AI provider *you* configured with *your* API key (post text is always plain text, HTML stripped and truncated):

- *Immediate replies:* the student post being answered and the forum description.
- *Daily digest:* student posts from the last 24 hours.
- *Reactivation:* the forum name, forum description, discussion subject and the recent posts of the discussion by every participant, teachers included.

In daily-digest and reactivation modes, authorship is replaced by anonymous sequential labels first.

**Never leaves your site:** names, usernames, email addresses, user IDs, IP addresses, course identifiers, grades.

**Stored by the plugin:** per-forum configuration (including the user ID of the designated assistant account), a daily counter of API calls per forum, and one AI evaluation per student and forum (grade, short justification, number of posts assessed, status). No message content.

All declared through Moodle's Privacy API. Administrators should confirm their institution's data-processing agreements cover the transfer of forum content to the chosen provider, and reflect it in the site privacy notice.

## Capabilities

| Capability | Default roles | Purpose |
|---|---|---|
| `local/forumia:managesettings` | editingteacher, manager | Configure Forumia for a forum |
| `local/forumia:actasassistant` | none (assign at system level) | Designates an account the assistant may publish from |
| `mod/forum:grade` (core) | editingteacher, teacher, manager | Review AI grade suggestions; required to switch on automatic grading |
